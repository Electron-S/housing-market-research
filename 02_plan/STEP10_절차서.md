# STEP 10: 보고서 집필 준비

## 목적
STEP0~9의 분석 결과를 바탕으로 보고서의 장구성·핵심 메시지·집필 방향을 확정한다.
실제 집필은 STEP11에서 수행하며, 이 단계의 산출물은 집필 설계도(`STEP10_output.md`)다.

## 입력
- STEP0~9 output 전체
- 산출물 유형에 맞는 템플릿:
  - `02_plan/템플릿_아파트시장조사.md`
  - `02_plan/템플릿_상가시장조사.md`
  - `02_plan/템플릿_권역시장브리프.md`
  - `02_plan/템플릿_사업지입지분석.md`
  - `02_plan/템플릿_경쟁단지비교.md`

## 작업 체크리스트
- [ ] 산출물 유형 확인 후 해당 템플릿 선택
- [ ] 장구성(챕터 목차) 확정 — 템플릿 구조를 기준으로 가감
- [ ] 챕터별 핵심 메시지 1~2문장씩 정리
- [ ] 챕터 ↔ STEP output 매핑 작성 (어느 챕터가 어느 STEP 결과를 쓰는지)
- [ ] STEP9 결론을 Executive Summary에 배치하는 두괄식 구성 확인
- [ ] STEP0 인계 내용(사업 단계·GS 포지션)을 서론 또는 사업 개요에 반영할 위치 지정
- [ ] STEP0의 수주 전/후에 따라 보고서 결론 방향 확정
  - **수주 후:** GS건설 분양·임대 실행안 포함
  - **수주 전:** GS건설 수주 제안 조건 및 타당성 판단 포함
- [ ] 상가 시장조사인 경우 STEP9의 `층별 적정 평단가 밴드 표`를 어느 챕터에 삽입할지 지정
- [ ] 집필 파일명 확정 (파일명 규칙: `STEP11_절차서.md`)

## 산출물
`04_workspace/[target_id]_[agent]_KR/STEP10_output.md`

### STEP10_output.md 형식
```markdown
# STEP10 산출물 — 보고서 집필 준비

## 보고서 유형·템플릿
- 유형: (아파트/상가/권역브리프/사업지분석/경쟁비교)
- 템플릿: 02_plan/템플릿_XXX.md
- 집필 파일명: STEP11_[유형]_draft.md

## 집필 방향
- GS건설 포지션: 수주 전/후
- 결론 방향: (제안 전략 / 분양·임대 전략)

## 장구성 및 핵심 메시지
| 챕터 | 핵심 메시지 | 사용하는 STEP output |
|---|---|---|
| Executive Summary | ... | STEP9 |
| 1. 사업 개요 | ... | STEP0·1 |
| ... | ... | ... |
```
